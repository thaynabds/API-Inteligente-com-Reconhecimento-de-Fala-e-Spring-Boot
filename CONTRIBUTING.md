# Contribuindo

Este repositório é principalmente uma entrega educacional do Bootcamp DIO: Java AI Copilot.

Para propor melhorias:

1. Crie uma branch descritiva.
2. Faça a alteração mantendo a separação entre `domain`, `application` e `infrastructure`.
3. Adicione ou atualize os testes necessários.
4. Execute `gradle test` antes de abrir um pull request.
5. Descreva claramente a motivação e o impacto da mudança.
